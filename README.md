# ☀️ Solstice

### Your music. In full color.

**Solstice 3.1.8** is an immersive Spicetify theme featuring artwork-driven colors, glass interfaces, synchronized lyrics, and a customizable player. Made by Crystal.

**🌐 [Official website](https://y2kbeatzz-dot.github.io/Solstice/)** · **[Preview](preview.svg)** · **[Report an issue](https://github.com/y2kbeatzz-dot/Solstice/issues)**

![Solstice preview](preview.svg)

## Features

- **Artwork-powered colors** — accents and lighting respond to the album cover.
- **Synchronized lyrics** — sidebar, floating lyrics, and immersive lyric views with a built-in editor.
- **Immersive Mode** — a fullscreen player with visualizer, artwork, vinyl, and karaoke effects.
- **Solstice Studio** — appearance, blur, glass, motion, and accessibility controls.
- **Lightweight playback updates** — shared lyric timing and cached rendering in version 3.1.8.

## Version 3.1.8

A small performance-focused release. It reduces repeated playback and lyric calculations while preserving Solstice's animations, Studio controls, visuals, and immersive experience.

Built for the Spicetify community. Not affiliated with Spotify or Spicetify.
