# ☀️ Solstice

### Your music. In full color.

**Solstice 3.1.11** is an immersive Spicetify theme featuring artwork-driven colors, glass interfaces, synchronized lyrics, and a customizable player. Made by Crystal.

![Solstice preview](preview.svg)

## Features

- **Artwork-powered colors** — accents and lighting respond to the album cover.
- **Synchronized lyrics** — sidebar, floating lyrics, and immersive lyric views with a built-in editor.
- **Immersive Mode** — a fullscreen player with visualizer, artwork, vinyl, and karaoke effects.
- **Solstice Studio** — appearance, blur, glass, motion, and accessibility controls.
- **Lightweight playback updates** — shared lyric timing and cached rendering in version 3.1.11.

## Version 3.1.11

Improves the explicit-content **E** badge rendering with Spotify's track-row badge selector and a font-independent fallback. The earlier song play-button, expanded Now Playing, performance, lyrics and Immersive Mode improvements remain included.
