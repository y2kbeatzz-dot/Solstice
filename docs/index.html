GET STARTED

Install Solstice

Best option: use Spicetify Marketplace inside Spotify. The public listing may take time to appear or refresh after a new release.

01 · Get Spicetify

Install Spicetify and its Marketplace app.

02 · Find Solstice

Open Spotify → Marketplace → Themes. Search for Solstice.

03 · Apply

Install the theme, then restart Spotify if your changes don't appear immediately.
